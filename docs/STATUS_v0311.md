### Class balance (subject 1, series 1 only)
- 119,496 frames. Each of the six events has 34 windows of exactly 150 frames, so 5,100 "on" frames each (4.27%).
- "Always off" scores 95.7% accuracy per event. Chance mAP per event is about 0.043.
- Any event on: 23,045 frames (19.29%). Six separate events would give 30,600, so 7,555 counts are repeats.
- 6,109 frames (26.5% of "on" frames) have two or more events on at once. Some frames have three or more, because the repeats (7,555) exceed the overlap frames (6,109).
- Overlap is a labelling effect: a frame is "on" within 75 frames (150 ms) of an event, so events closer than 150 frames apart get overlapping windows. Labels come from the experiment's sensors, not the EEG (verify in the dataset paper).
- The earlier impression from the meeting that overlap is rare was wrong for this series.

## 4. Decisions
- Two-phase plan: compare existing methods first, then build a targeted method (Peter).
- At most two non-HDC baselines plus the logistic regression floor. Baselines sit in a similar accuracy and cost range as HDC.
- Dense binary or bipolar HDC (BSC or MAP). No sparse or hybrid models for now. Dimension fixed at 10,000.
- Inference must be causal. Training cost does not matter.
- Keep the bandpass and CSP pipeline for now and note which steps need domain knowledge.
- Simplest HDC baseline: tabular, no temporal context. Then temporal variants.
- The six outputs are multi-label (independent sigmoids). A softmax over six events is wrong because events overlap.
- Evaluation standard: all upcoming models will be evaluated using all 3 confusion matrix strategies ((a) 2x2 per event, (b) 7-class non-overlap, (c) 7-class nearest-instant) alongside ROC-AUC, mAP, and UAR metrics.
- Leave-one-subject-out evaluation is planned after the within-subject baselines.
